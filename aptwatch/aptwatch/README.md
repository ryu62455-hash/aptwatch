# 실거래 리포트 자동 사이트

국토교통부 아파트 매매 실거래가(공공데이터포털)를 **매일 자동으로** 받아서 지역별 거래 동향, 최고가 경신 단지, 단지별 거래 이력 페이지를 만들고 무료로 배포합니다. 한 번 설정하면 사람이 손댈 일이 없습니다. 수익은 사이트에 붙이는 구글 애드센스 광고에서 나옵니다.

## 먼저 알아둘 것

- 수익은 보장되지 않습니다. 검색 노출까지 보통 수개월이 걸리고, 애드센스는 별도 심사를 통과해야 합니다.
- 이 코드는 실제 API로 호출 테스트를 하지 못한 상태입니다. 아래 3단계의 `--check` 결과를 꼭 확인하세요. 샘플 데이터 빌드와 응답 파서는 테스트를 마쳤습니다.
- 사이트 문구는 정보 제공용입니다. 공공데이터 이용 조건과 출처 표기는 공공데이터포털의 해당 데이터 페이지에서 직접 확인하세요.

## 설정 순서 (약 30분)

### 1. 인증키 받기
1. [공공데이터포털](https://www.data.go.kr) 가입
2. "국토교통부_아파트 매매 실거래가 상세 자료" 검색 후 **활용신청** (보통 바로 승인)
3. 마이페이지에서 **일반 인증키(Decoding)** 복사

### 2. 내 컴퓨터에서 먼저 확인
```
export DATA_GO_KR_KEY="복사한 인증키"
python build.py --check
```
태그 목록이 나오고 "변환 성공"이 보이면 정상입니다. "변환 실패"가 나오면 출력된 태그 이름을 알려 주세요. 코드의 `pick(...)` 부분만 고치면 됩니다.

미리보기는 `python build.py --demo` 후 `preview/index.html`을 열어 보세요. 샘플 데이터라 공개하면 안 됩니다.

### 3. GitHub에 올리고 자동화
1. GitHub에서 새 저장소 만들기 (예: `aptwatch`)
2. 이 폴더의 파일을 모두 올리기 (`.github` 폴더 포함)
3. 저장소 **Settings → Secrets and variables → Actions**에서 `DATA_GO_KR_KEY` 이름으로 인증키 등록
4. **Settings → Pages → Source**를 `GitHub Actions`로 변경
5. `config.json`의 `site_url`을 `https://내아이디.github.io/aptwatch`로 수정하고 `regions`를 원하는 지역으로 바꾸기 (코드는 법정동코드 앞 5자리)
6. **Actions → 매일 자동 갱신 → Run workflow**로 첫 실행. 이후 매일 한국시간 오전 7시에 자동 갱신

### 4. 검색 노출
- [구글 서치콘솔](https://search.google.com/search-console)과 네이버 서치어드바이저에 사이트를 등록하고 `사이트주소/sitemap.xml`을 제출
- 지역을 늘릴수록 페이지 수가 늘어납니다. API 하루 호출 한도(개발계정 기준 1,000건)를 넘지 않게 지역 수를 조절하세요. 지난 달 이전 데이터는 캐시를 재사용합니다.

### 5. 광고 붙이기
- 사이트 소개, 개인정보처리방침 페이지는 이미 포함되어 있습니다. `config.json`의 `contact_email`을 본인 메일로 바꾸세요.
- 개인 도메인 연결을 권장합니다. 애드센스 승인 후 `adsense_client`(`ca-pub-...`)와 `adsense_slot`(광고 단위 숫자)을 `config.json`에 넣으면 광고가 자동으로 들어갑니다.

## 파일 구성
- `build.py` 수집, 분석, 페이지 생성 전체
- `config.json` 지역, 사이트 이름, 광고 설정
- `.github/workflows/daily.yml` 매일 실행과 배포
